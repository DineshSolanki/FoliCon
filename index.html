Features:

🎨 Poster Mode & Built-in Overlays

  • 6 Built-in Overlay Designs: Legacy, Alternate, Faelpessoal, Liaher, Faelpessoal Horizontal, and modern Windows 11 Style.
  • Dynamic Rating Badges: Fetch ratings from TMDB or IGDB and display rating shields directly on your icons, or set custom scores.
  • Multi-Video Trailers: Watch trailers and gameplay clips directly inside FoliCon for movies, TV series, and games.
  • High-Resolution Previews: Browse posters with full transparent PNG preview rendering before selecting.
  • Plex Standard Naming: Native support for Title (Year) {tmdb/imdb/tvdb-id} folder structures.

🛒 Community Overlay Store & Visual Designer New

  • Community Overlay Store: Browse, preview, and 1-click install custom icon overlay styles from the FoliCon-Overlays community repository.
  • WYSIWYG Overlay Designer: Built-in visual designer to customize layouts, text styling, and positioning with a real-time live folder preview.
  • Data-Driven Packages: Overlays are lightweight packages that update independently without requiring an app upgrade.

🖼️ Professional Mode

  • DeviantArt Creator Packs: Access thousands of ready-made, handcrafted icons created by talented artists.
  • Watcher-Exclusive Downloads: Authenticate with DeviantArt OAuth to unlock creator-exclusive icons directly in-app.
  • Extract Gallery: Automatically unpack and select individual folder icons from ZIP and RAR archive submissions.

⚡ Automation, Security & Integration

  • Advanced Subfolder Processing: Scan deep folder hierarchies with configurable depth limits, root folder icon options, and skip-already-processed filters.
  • Bring Your Own Key (BYOK) Security: Your TMDB, IGDB, and DeviantArt credentials stay on your machine, encrypted with Windows DPAPI.
  • Custom Icon Setter: Order and batch-apply your own downloaded .ico or .png files to folders.
  • Windows Explorer Integration: Optional right-click context menu integration to customize folders directly from File Explorer.
  • Multi-Language Support: Available in 6 languages (English, Hindi, Spanish, Arabic, Russian, Portuguese) with active Crowdin community translations.
